DARKER LIGHT ASTROLOGY THEME

Install
1. In WordPress, open Appearance > Themes > Add New Theme > Upload Theme.
2. Select darker-light-astrology-theme.zip, install it, then activate the theme.
3. Open the site's home page to see the one-page design.

The theme preserves the supplied homepage copy and provides responsive styling. The contact form is still a visual placeholder and does not send messages. Connect a form plugin or configure a mail handler before publishing it for visitors.

The separate Darker Light Astrology API plugin provides only service status routes. Chart calculations and birth-data handling are not included yet.
